SmolVLA + LeRobot

SmolVLA: A Vision-Language-Action Model for Affordable and Efficient Robotics arXiv:2506.01844

This guide is self-contained in the AI Research Lab.

Prerequisites & Knowledge Graph

Feedback Control → Behavior Cloning → VLMs → Flow Matching + Chunking → Asynchronous Execution → SmolVLA + LeRobot

Core Idea

Compact VLA (~450M params) trained on community data. Uses lightweight VLM + flow matching action expert + asynchronous inference.

Detailed Sections

  • Motivation: Why small VLAs matter for accessible robotics
  • Architecture: VLM backbone (lightweight with layer skipping) + Action Expert (flow matching)
  • Flow Matching for fast action generation (straight path from noise to data)
  • Asynchronous execution for real-time control (decouples perception from action)
  • LeRobot full stack integration (datasets, training, hardware, evaluation)

Primary Resources

  • Paper: https://arxiv.org/abs/2506.01844
  • Blog: https://huggingface.co/blog/smolvla
  • Code: https://github.com/huggingface/lerobot

Caveats

Simulation vs real metrics differ. Check versions. Asynchronous mainly helps task time.
