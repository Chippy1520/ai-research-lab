## Brief description

Foundation-model agents combine a pretrained model with tools, external memory, and a control loop; reliability depends on grounding each action, managing state, and verifying outcomes rather than treating fluent plans as execution.

## Recall in 30 seconds

- The agent loop observes, updates state, selects a tool or response, executes, and incorporates the result.
- Working context, episodic history, and durable semantic memory have different lifetimes and failure modes.
- Tool schemas and permissions define the action space and must constrain irreversible operations.
- Planning benchmarks should measure completion, recovery, cost, and factual grounding across long horizons.
